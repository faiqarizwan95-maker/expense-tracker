# Expense Tracker

A simple and clean Expense Tracker web app built with HTML, CSS, and JavaScript.

## Features

- Add income and expense transactions
- Categorize transactions (Food, Salary, Bills, etc.)
- Automatic date for every transaction
- Real-time balance, income, and expense calculation
- Delete transactions
- Data saved in LocalStorage (data remains after refresh)

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- LocalStorage

## How to Use

1. Enter description
2. Enter amount (positive for income, negative for expense)
3. Select category
4. Click "Add Transaction"
